# Porsche Sales Intelligence

Dashboard interativa para análise de vendas de veículos Porsche

## Funcionalidades

- Filtro por modelo Porsche
- Filtro por ano do modelo
- Filtro por cidade
- Filtro por método de pagamento
- Análise de vendas por cidade e estado
- Identificação dos métodos de pagamento mais utilizados
- Ranking de modelos mais vendidos
- Insights de comportamento de compra por região
- Evolução das vendas ao longo do tempo
